Памятка по работе с javadoc
Комментарии в стиле Javadoc могут содержать HTML-теги.
Можно размещать над классом, методом, полем.

Содержание:
Описание того, что комментируется
Отдельные блочные теги (отмеченные символом «@»), которые описывают конкретные метаданные.

Бывают - отдельные и встроенные теги
{@link} можно использовать ссылаясь на часть кода
@author имя автора который добавил код
@param содержит любое полезное описание параметра метода или входных данных.
@return содержит описание того, что метод возвращает или может возвратить
@see генерирует ссылку, аналогичную тегу {@link}, но в контексте ссылки
@since указывает, какая версия класса, поля или метода была добавлена в проект
@version указывает версию программного обеспечения, обычно используется с макросами %I% и %G%
@throws используется для дальнейшего объяснения случаев, когда программа ожидает исключения
@deprecated дает объяснение, почему код устарел, когда он мог быть устаревшим и каковы альтернативы.
