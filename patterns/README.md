Домашнее задание: применить паттерны проектирования по одному из каждой группы.

Для реализации была выбрана модель - эмулятор АТМ, построенный согласно принципам solid

Цели:
- добавить различные номиналы банкнот
- реализовать "меню" банкомата

АТМ может принимать банкноты разных номиналов, выдавать запрошенную сумму, показывать сумму остатка денежных средств.

Для реализации ячеек номиналов был использована Фабрика (пакет .banknotes);
Для реализации хранилища банкнот был использован Компоновщик (пакет .storage);
Для реализции поведения эмулятора банкомата использован Состояние (пакет .atm);
